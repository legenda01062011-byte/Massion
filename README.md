Запуск

Основной файл бота:

"main.py"

Зависимости устанавливаются из:

"requirements.txt"

Токен бота задаётся через переменную окружения:

"BOT_TOKEN"

База данных по умолчанию:

"tracker.db"

Команды

Основная команда:

"/start"

Для просмотра дел:

"/today"

Бот работает через Telegram polling.
